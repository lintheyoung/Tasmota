# GUI 证书切换功能说明

## 📋 功能概述

GUI 版本的设备模拟器现在支持在界面中动态切换 AWS IoT 证书文件，无需修改代码或配置文件。

## 🎯 主要特性

### ✅ 已实现的功能

1. **证书文件选择器**
   - 设备证书（.pem / .crt）
   - 私钥文件（.key / .pem）
   - CA 根证书（.pem / .crt）
   - 支持文件浏览对话框

2. **证书验证**
   - 检查文件是否存在
   - 使用 OpenSSL 验证证书格式
   - 显示证书主体信息
   - 显示证书有效期

3. **配置管理**
   - 自动保存到 `gui_config.json`
   - 启动时自动加载上次配置
   - JSON 格式，易于手动编辑

4. **动态连接**
   - 使用选择的证书建立 MQTT 连接
   - 支持在运行前更换证书
   - 无需重启程序

## 🚀 使用指南

### 基本使用流程

1. **启动 GUI**
   ```bash
   python3 gui_main.py
   ```

2. **选择证书文件**
   - 在顶部"🔐 证书配置"区域
   - 点击每行右侧的"浏览"按钮
   - 选择对应的证书文件

3. **验证证书**（可选但推荐）
   ```
   点击"验证证书"按钮
   → 查看日志区域的验证结果
   ```

4. **保存配置**（可选）
   ```
   点击"保存配置"按钮
   → 配置保存到 gui_config.json
   → 下次启动自动加载
   ```

5. **启动模拟器**
   ```
   点击"启动模拟器"按钮
   → 使用当前选择的证书连接 AWS IoT
   ```

### 切换不同设备的证书

如果您有多个 AWS IoT 设备，可以快速切换：

1. **停止当前连接**（如果正在运行）
   ```
   点击"停止模拟器"按钮
   ```

2. **选择新的证书文件**
   ```
   - 浏览选择新设备的证书
   - 浏览选择新设备的私钥
   - CA 证书通常不变
   ```

3. **保存新配置**（可选）
   ```
   点击"保存配置"
   ```

4. **重新启动**
   ```
   点击"启动模拟器"
   ```

## 📁 配置文件格式

`gui_config.json` 示例：

```json
{
  "cert_path": "/path/to/IoT-Gateway-000011.cert.pem",
  "key_path": "/path/to/IoT-Gateway-000011.private.key",
  "ca_path": "/path/to/AmazonRootCA1.pem"
}
```

## 🔍 证书类型支持

### 当前使用的证书

- **类型**: ECC P-256（椭圆曲线）
- **算法**: ECDSA with SHA-256
- **颁发者**: Amazon Web Services
- **用途**: AWS IoT mTLS 认证

### 支持的其他证书类型

✅ **RSA 证书**
- RSA 2048 位
- RSA 4096 位

✅ **ECC 证书**
- P-256（当前使用）
- P-384
- P-521

## 🔐 证书验证功能

点击"验证证书"按钮后，系统会：

1. **检查文件存在性**
   ```
   ✓ 证书文件存在
   ✓ 私钥文件存在
   ✓ CA 证书文件存在
   ```

2. **验证证书格式**（需要 OpenSSL）
   ```
   使用 openssl x509 命令验证证书
   显示证书主体（Subject）
   显示证书有效期（Validity）
   ```

3. **输出到日志区域**
   ```
   [成功] 证书验证通过
     证书主体: CN=AWS IoT ECC Certificate
     notBefore=Oct 15 12:56:42 2025 GMT
     notAfter=Dec 31 23:59:59 2049 GMT
   ```

# GUI 启动连接时
def run_simulation_thread(self):
    # 获取界面中的证书路径
    self.cert_path = self.cert_entry.get()
    self.key_path = self.key_entry.get()
    self.ca_path = self.ca_entry.get()

    # 连接到 AWS IoT
    self.mqtt_client.connect()

## ⚠️ 注意事项

1. **证书路径**
   - 支持相对路径和绝对路径
   - 建议使用绝对路径避免歧义

2. **证书权限**
   - 确保证书文件有读取权限
   - 私钥文件建议设置 600 权限

3. **证书匹配**
   - 证书和私钥必须配对
   - 证书必须与 AWS IoT Thing 关联
   - Thing Name 在 `config.py` 中配置

4. **配置持久化**
   - `gui_config.json` 不会被 Git 追踪
   - 每次点击"保存配置"才会更新文件
   - 删除该文件可恢复默认配置

## 🐛 故障排查

### 问题：证书验证失败

**原因**：
- 文件路径错误
- 证书文件损坏
- OpenSSL 未安装

**解决方法**：
```bash
# 1. 检查文件是否存在
ls -l /path/to/cert.pem

# 2. 手动验证证书
openssl x509 -in /path/to/cert.pem -noout -text

# 3. 检查文件权限
chmod 644 cert.pem
chmod 600 private.key
```

### 问题：连接失败

**原因**：
- 证书与 Thing 不匹配
- 证书已过期
- CA 证书错误

**解决方法**：
1. 在 AWS IoT Console 检查 Thing 的证书
2. 确认证书有效期
3. 使用正确的 Amazon Root CA

### 问题：配置未保存

**原因**：
- 文件写入权限不足
- 路径包含特殊字符

**解决方法**：
```bash
# 检查目录权限
ls -ld /path/to/PythonDeviceSim

# 手动创建配置文件
touch gui_config.json
chmod 644 gui_config.json
```
