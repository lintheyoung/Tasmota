## 📦 区域说明

### 1. 证书配置区（高度: ~120px）
- **位置**: 顶部
- **功能**:
  - 3个文件路径输入框
  - 3个浏览按钮
  - 验证和保存按钮
- **样式**:
  - 字体: 11-13px
  - 输入框宽度: 350px
  - 按钮尺寸: 60-80px × 25px

### 2. 状态栏（高度: ~40px）
- **位置**: 证书区下方
- **功能**:
  - 左侧: 连接状态指示（● 未连接/已连接/错误）
  - 右侧: 运行时间（HH:MM:SS）
- **样式**: 字体 12px

### 3. 数据显示区（高度: ~40px）
- **位置**: 状态栏下方
- **功能**: 单行显示所有关键数据
  - 传感器: 振动、电池、状态
  - 统计: 遥测、确认、成功率、事件
- **样式**:
  - 字体: 11px
  - 水平排列，用 "|" 分隔

### 4. 日志区（高度: ~380px，自适应）
- **位置**: 中间，占据最大空间
- **功能**:
  - 实时显示日志输出
  - 自动滚动到底部
  - 可手动滚动查看历史
- **样式**:
  - 等宽字体 Monaco 10px
  - 自动换行

### 5. 控制按钮区（高度: ~50px）
- **位置**: 底部
- **功能**:
  - 左侧: 启动/停止按钮（绿色/红色）
  - 右侧: 日志操作和调试开关
- **样式**:
  - 主按钮: 100px × 30px
  - 辅助按钮: 80px × 30px

## 🎯 设计原则

### 紧凑性
- 所有边距从 10px 减小到 5-8px
- 字体从 12-14px 减小到 10-13px
- 按钮高度从 35px 减小到 25-30px

### 可见性
- 启动/停止按钮使用醒目的绿色/红色
- 使用图标符号（▶ ⏹）增强辨识度
- 状态使用彩色圆点（●）

### 信息密度
- 数据区从 2列布局改为单行布局
- 移除不常用的"命令"统计
- 标签文字简化（"证书"代替"设备证书"）

## 📱 响应式特性

虽然窗口大小固定为 1000×700，但内部布局具有以下特性：

1. **日志区自适应**
   - 使用 `expand=True` 填充剩余空间
   - 窗口拉伸时日志区高度增加

2. **横向填充**
   - 所有区域使用 `fill="x"` 横向填充
   - 输入框宽度固定，但区域整体自适应

3. **文本自动换行**
   - 日志区使用 `wrap="word"`
   - 长文本自动换行，不会横向溢出

## 🔧 自定义建议

如果需要进一步调整布局，可以修改 `gui_main.py` 中的以下参数：

```python
# 窗口大小（第 35 行）
self.geometry("1000x700")  # 改为其他尺寸

# 边距（各区域的 padx, pady）
.pack(padx=8, pady=5)  # 增大或减小边距

# 字体大小
font=ctk.CTkFont(size=11)  # 调整字体大小

# 按钮尺寸
width=100, height=30  # 调整按钮大小
```
